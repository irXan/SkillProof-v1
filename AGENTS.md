# SkillProof MVP

## Product
SkillProof helps beginner Pakistani freelancers turn projects into client-ready proof: portfolio case studies, bios, Upwork/Fiverr profiles, proposals, and interview practice.

## Stack
- Next.js App Router + TypeScript
- Tailwind CSS
- shadcn/ui
- Supabase
- Vercel AI SDK
- OpenAI-compatible AI API

## Design system
- Background: #0B1F3A
- Card: #122C4F
- Elevated card: #0F2A4C
- Accent: #12B5A5
- Text: #FFFFFF
- Secondary text: #D7E3EE
- Muted text: #8FA3B8
- Border: #22405F

## Rules
- Keep the app dark-theme first.
- Keep the UI minimal, professional, and mobile responsive.
- Do not add payments, PDF export, public hosting, social login, or Upwork integration.
- Never expose AI_API_KEY to the client.
- If AI is unavailable, use Demo Mode with realistic sample output.
- Do not invent user metrics, revenue, testimonials, or traction.
- Preserve existing working functionality.
- Run `npm run dev` and verify the full user flow after major changes.
